This package vendors the Dreamer world-model implementation from the original
WMP repository:

  E:\开源项目\WMP-master\WMP-master\dreamer

The original WMP repository declares the Dreamer files as derived from
dreamerv3-torch under the MIT license. The vendored Python files retain their
original MIT license headers.

Local changes are limited to MjLab adapter compatibility, including CPU-safe
initialization for fixed distribution standard deviations.
