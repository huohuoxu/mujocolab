# WMP Go1 运行指令

任务 ID：

```sh
Mjlab-WMP-Rough-Unitree-Go1
```


 先进入仓库根目录再运行训练命令，不要在 `src` 目录下直接启动：

  ```sh
  cd /home/daji/users/xuyan/my_project/mujocolab
  ```

  训练脚本默认日志根目录是 `logs/rsl_rl`，这是相对“当前终端所在目录”解析的。
  如果当前目录是：

```sh
/home/daji/users/xuyan/my_project/mujocolab/src
```

  那么训练结果会保存到：

```sh
/home/daji/users/xuyan/my_project/mujocolab/src/logs/rsl_rl
```

  如果必须在 `src` 目录下运行，请显式指定日志根目录：

```sh
uv run train Mjlab-WMP-Rough-Unitree-Go1 \
  --gpu-ids "[0]" \
  --env.scene.num-envs 64 \
  --agent.max-iterations 5 \
  --agent.logger tensorboard \
  --log-root ../logs/rsl_rl
```

一、开始训练：

  1、如果服务器可以连接 wandb

```sh
uv run train Mjlab-WMP-Rough-Unitree-Go1 \
  --gpu-ids "[0]" \
  --env.scene.num-envs 1024
```

  2、服务器无法连接 wandb，使用 tensorboard 记录日志

```sh
uv run train Mjlab-WMP-Rough-Unitree-Go1 \
  --gpu-ids "[0]" \
  --env.scene.num-envs 1024 \
  --agent.logger tensorboard
```

  3、工程回归短训

```sh
uv run train Mjlab-WMP-Rough-Unitree-Go1 \
  --gpu-ids "[0]" \
  --env.scene.num-envs 64 \
  --agent.max-iterations 5 \
  --agent.logger tensorboard
```

      注意：WMP runner 默认只在第 1 个 iteration 和每 10 个 iteration 打印一次
      `[WMP] iter=...`。所以 `--agent.max-iterations 5` 时，终端通常只会看到
      `iter=1`，后续标量主要写入 TensorBoard，训练结束会保存 `model_5.pt`。

  4、CPU 接口 smoke，只用于检查链路，速度会比较慢

```sh
uv run train Mjlab-WMP-Rough-Unitree-Go1 \
  --gpu-ids null \
  --env.scene.num-envs 4 \
  --agent.max-iterations 1 \
  --agent.num-steps-per-env 2 \
  --agent.logger tensorboard
```

  5、断点续训并且继续用 tensorboard 记录日志

      比如说当前加载的模型是训练了 5000 个 iteration，
      然后训练脚本设置再训练 5000 个 iteration，
      断点续训就会加载已训练 5000 个 iteration 的模型，再继续训练 5000 个 iteration。

```sh
uv run train Mjlab-WMP-Rough-Unitree-Go1 \
  --gpu-ids "[0]" \
  --env.scene.num-envs 1024 \
  --agent.logger tensorboard \
  --agent.resume True \
  --agent.load-run "2026-06-24_17-35-16_m10_64env_5iter_fixed" \
  --agent.load-checkpoint "model_5.pt"
```

二、训练中查看奖励曲线：

  1、直接登录 wandb

      wandb 是在线查看模式，所以服务器需要能连接 wandb。

  2、tensorboard 记录日志

      终端输入：

```sh
uv run tensorboard --logdir logs/rsl_rl/go1_wmp --bind_all
```

      终端出现类似输出后，注意端口号：

```text
TensorBoard 2.20.0 at http://admin123-AS4110G-D04R-G3:6007/ (Press CTRL+C to quit)
```

      本地浏览器打开：

```text
http://<你的服务器IP地址>:6007
```

三、训练结束后查看训练效果（本地查看）：

```sh
uv run play Mjlab-WMP-Rough-Unitree-Go1 \
  --checkpoint-file E:\My_Project\mujocolab\logs\rsl_rl\go1_wmp\<run_name>\model_5000.pt \
  --viewer native
```

四、WMP 专用注意事项：

  1、AMP motion 数据

      默认读取：

```sh
src\mjlab\tasks\WMP\data\mocap_motions\*.txt
```

      临时使用原 WMP 仓库数据目录：

```powershell
$env:WMP_MOTION_DATA_DIR = "E:\开源项目\WMP-master\WMP-master\datasets\mocap_motions"
uv run train Mjlab-WMP-Rough-Unitree-Go1 --gpu-ids "[0]" --env.scene.num-envs 1024
```

      Linux 服务器上使用：

```sh
export WMP_MOTION_DATA_DIR=/home/daji/users/xuyan/WMP-master/WMP-master/datasets/mocap_motions
uv run train Mjlab-WMP-Rough-Unitree-Go1 --gpu-ids "[0]" --env.scene.num-envs 1024
```

      如果终端出现：

```text
[WMP] No AMP motion files loaded; training falls back to task reward.
```

      说明当前没有读到 `*.txt` motion 文件。请检查 `WMP_MOTION_DATA_DIR`
      是否指向原 WMP 的 `datasets/mocap_motions` 目录，或者把 motion txt 文件复制到：

```sh
src/mjlab/tasks/WMP/data/mocap_motions/
```

  2、Windows 下如果默认 uv 缓存目录没有权限，可以把缓存放到仓库内：

```sh
uv --cache-dir .uv-cache run train Mjlab-WMP-Rough-Unitree-Go1 \
  --gpu-ids "[0]" \
  --env.scene.num-envs 64 \
  --agent.max-iterations 5 \
  --agent.logger tensorboard
```

  3、MuJoCo/Warp 相机首次编译 kernel 如果没有用户缓存权限，请在创建环境前设置：

```python
import warp as wp

wp.config.kernel_cache_dir = ".warp-cache"
```
