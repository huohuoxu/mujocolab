# WMP Go1 运行指令

任务 ID:

```sh
Mjlab-WMP-Rough-Unitree-Go1
```

## 1. 基础检查

Windows 下如果默认 uv 缓存目录没有权限，可以把缓存放到仓库内：

```sh
uv --cache-dir .uv-cache run list-envs
```

只检查 WMP 新包能否编译：

```sh
uv --cache-dir .uv-cache run python -m py_compile src\mjlab\tasks\WMP\wmp_env_cfg.py src\mjlab\tasks\WMP\terrains.py src\mjlab\tasks\WMP\rl\config.py src\mjlab\tasks\WMP\rl\modules.py src\mjlab\tasks\WMP\rl\amp.py src\mjlab\tasks\WMP\rl\runner.py
```

如果 MuJoCo/Warp 相机 smoke test 首次编译 kernel 时没有用户缓存权限，请在
Python 脚本里创建环境前设置：

```python
import warp as wp

wp.config.kernel_cache_dir = ".warp-cache"
```

## 2. 短训 smoke

推荐先用很小规模验证工程链路：

```sh
uv --cache-dir .uv-cache run train Mjlab-WMP-Rough-Unitree-Go1 --gpu-ids "[0]" --env.scene.num-envs 64 --agent.max-iterations 5 --agent.logger tensorboard
```

CPU 只能用于接口 smoke，速度会比较慢：

```sh
uv --cache-dir .uv-cache run train Mjlab-WMP-Rough-Unitree-Go1 --gpu-ids null --env.scene.num-envs 4 --agent.max-iterations 1 --agent.num-steps-per-env 2 --agent.logger tensorboard
```

M10 工程回归已通过的配置为 64 env、5 iterations、tensorboard logger。CPU 可跑通，
但耗时明显；后续建议优先用 GPU：

```sh
uv --cache-dir .uv-cache run train Mjlab-WMP-Rough-Unitree-Go1 --gpu-ids "[0]" --env.scene.num-envs 64 --agent.max-iterations 5 --agent.logger tensorboard
```

## 3. AMP motion 数据

默认会读取：

```sh
src\mjlab\tasks\WMP\data\mocap_motions\*.txt
```

也可以临时指定原 WMP 仓库数据目录：

```powershell
$env:WMP_MOTION_DATA_DIR = "E:\开源项目\WMP-master\WMP-master\datasets\mocap_motions"
uv --cache-dir .uv-cache run train Mjlab-WMP-Rough-Unitree-Go1 --gpu-ids "[0]" --env.scene.num-envs 64 --agent.max-iterations 5
```

`MotionLoader` 支持原仓库 JSON txt 格式，并会把帧转换为 AMP obs：
`joint_pos(12), base_lin_vel(3), base_ang_vel(3), joint_vel(12)`。

## 6. 当前实现边界

当前 WMP 是可运行复现框架第一版：环境、观测、深度相机、WMP runner、
RSSM/Dreamer 风格世界模型训练目标、深度预测器、AMP discriminator、
checkpoint 和 Go1 rough terrain 已经接通。

世界模型已经包含 action-conditioned prior、observation-conditioned posterior、
KL free-nats、dynamics/representation KL、prop/depth/reward/continuation heads。
后续长训前建议继续补齐原仓库的 world-model replay buffer、Conv image decoder、
symlog distribution、feet edge penalty 和更完整的 terrain mask。
