一、开始训练：
  1、如果服务器可以连接上wandb
      uv run train Mjlab-Velocity-Rough-Unitree-G1 \
        --gpu-ids "[5,6]" \
        --env.scene.num-envs 512
  2、服务器无法连接wandb，使用tensorboard记录日志
      uv run train Mjlab-Velocity-Rough-Unitree-G1 \
      --gpu-ids "[6,7]" \
      --env.scene.num-envs 5120 \
      --agent.logger tensorboard
  
  3、断点续练并且继续用 tensorboard 记录日志
      比如说当前加载的模型是训练了  1500 个iteration
      然后训练脚本是每次训练        1500个iteration
      断点续训就会加载训练了  1500个iteration的模型 再训练 1500 个iteration
      uv run train Mjlab-Velocity-Rough-Unitree-G1 \
      --gpu-ids "[6,7]" \
      --env.scene.num-envs 4096 \
      --agent.logger tensorboard \
      --agent.resume True \
      --agent.load_run "2026-04-16_15-45-26" \
      --agent.load_checkpoint "model_49997.pt"


二、训练中查看奖励曲线
  1、直接登录wandb
      wandb是在线查看模式，所以需要服务器也挂梯子
      
  2、tensorboard记录日志
      终端输入
      uv run tensorboard --logdir <日志目录 例：logs/rsl_rl/go1_rear_biped_flat> --bind_all
      终端出现（注意端口号）
      TensorBoard 2.20.0 at http://admin123-AS4110G-D04R-G3:6007/ (Press CTRL+C to quit)
      本地浏览器打开 （端口号和上面对其）
      组内服务器地址：172.17.27.172
      http://<你的服务器IP地址>:6007
      

三、训练结束后查看训练效果（本地查看）
      uv run play Mjlab-RearBiped-HandstandAligned-Unitree-Go1 --checkpoint-file E:\mjlab\logs\rsl_rl\go1_rear_biped_handstand_aligned\2026-04-17_10-05-05\model_12000.pt --viewer native
